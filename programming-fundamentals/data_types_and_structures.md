# Data Types and Structures

## Course Overview:

This course covers Python's built-in data types and the core data structures used to organize and manipulate data. Through a series of lectures and coding exercises, students will learn how to choose the right data type or structure for a given problem and how to work with each of them effectively.

## Course Outline:

- Introduction to Data Types
  - What is a data type?
  - Mutable vs. immutable types
  - Type checking and conversion (`type()`, `int()`, `str()`, `float()`, etc.)
- Numeric and Text Types
  - Integers, floats, and complex numbers
  - Strings: indexing, slicing, and common methods
  - String formatting (f-strings, `.format()`, `%` operator)
- Sequence Types: Lists and Tuples
  - Creating, indexing, and slicing lists and tuples
  - List methods: append, insert, remove, sort, etc.
  - Mutability differences between lists and tuples
  - When to use a tuple instead of a list
- Set Types
  - Creating and modifying sets
  - Set operations: union, intersection, difference
  - Use cases for sets (deduplication, membership testing)
- Mapping Type: Dictionaries
  - Creating and modifying dictionaries
  - Accessing, updating, and deleting key-value pairs
  - Dictionary methods and iteration (`keys()`, `values()`, `items()`)
  - Nested data structures (lists of dicts, dicts of lists, etc.)
- Choosing the Right Data Structure
  - Comparing performance and use cases across lists, tuples, sets, and dictionaries
  - Common patterns for combining data structures to model real-world data
- Final Project
  - Putting it all together: a final project that models a small dataset using an appropriate combination of Python data types and structures.

By the end of this course, students will be comfortable working with Python's core data types and structures, and will be able to choose the right one for a given task based on mutability, ordering, and performance needs.
