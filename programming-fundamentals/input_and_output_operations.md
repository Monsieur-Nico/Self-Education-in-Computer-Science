# Input and Output Operations

## Course Overview:

This course covers how Python programs read input from users and files, and how they produce output. Through a series of lectures and coding exercises, students will learn how to interact with users via the console and how to read from and write to files on disk.

## Course Outline:

- Console Input and Output
  - Printing output with `print()` and formatting options
  - Reading user input with `input()`
  - Converting and validating user input
- Working with Files
  - Opening and closing files with `open()` and `close()`
  - The `with` statement for safe file handling
  - File modes: read, write, append, and binary modes
- Reading and Writing Text Files
  - Reading a file line by line vs. all at once
  - Writing and appending text to files
  - Working with plain text data formats (CSV)
- Structured Data Formats
  - Reading and writing JSON with the `json` module
  - Reading and writing CSV with the `csv` module
- File Paths and the Filesystem
  - Absolute vs. relative paths
  - Checking whether files and directories exist
  - Basic filesystem operations with the `os` and `pathlib` modules
- Final Project
  - Putting it all together: a final project that reads structured data from a file, processes it, and writes the results back out to a file.

By the end of this course, students will be comfortable handling both console-based input/output and file-based I/O in Python, including reading and writing structured data formats like JSON and CSV.
