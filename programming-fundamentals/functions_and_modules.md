# Functions and Modules

## Course Overview:

This course covers how to write reusable, organized Python code using functions and modules. Through a series of lectures and coding exercises, students will learn how to define and call functions, work with arguments and return values, and organize code across multiple files using modules and packages.

## Course Outline:

- Introduction to Functions
  - Why use functions? Code reuse and organization
  - Defining and calling functions with `def`
  - The `return` statement
- Function Arguments
  - Positional and keyword arguments
  - Default argument values
  - Variable-length arguments (`*args` and `**kwargs`)
- Scope and Lifetime of Variables
  - Local vs. global scope
  - The `global` keyword
  - Understanding variable lifetime within function calls
- Advanced Function Concepts
  - Lambda (anonymous) functions
  - Functions as first-class objects (passing functions as arguments)
  - Recursion basics
- Modules
  - What is a module, and why organize code into modules?
  - Importing modules with `import` and `from ... import`
  - Creating and importing your own modules
- Packages and the Standard Library
  - Organizing modules into packages
  - Commonly used standard library modules (`math`, `random`, `datetime`, `os`)
  - Installing and using third-party packages with `pip`
- Final Project
  - Putting it all together: a final project that organizes functionality into functions and modules, and reuses at least one standard library or third-party module.

By the end of this course, students will be able to write well-organized, reusable Python code using functions and modules, and will be comfortable navigating and using both the standard library and third-party packages.
