# Object-Oriented Programming Concepts

## Course Overview:

This course covers the fundamentals of object-oriented programming (OOP) in Python. Through a series of lectures and coding exercises, students will learn how to model problems using classes and objects, and how to apply core OOP principles such as encapsulation, inheritance, and polymorphism.

## Course Outline:

- Introduction to Object-Oriented Programming
  - What is OOP, and why use it?
  - Classes vs. objects (instances)
  - Comparing OOP to procedural programming
- Defining Classes and Objects
  - The `class` keyword and the `__init__` method
  - Instance attributes and methods
  - The `self` parameter
- Encapsulation
  - Public, protected, and private attributes (naming conventions)
  - Getters, setters, and properties
  - Class attributes vs. instance attributes
- Inheritance
  - Creating subclasses with inheritance
  - Overriding methods
  - Using `super()` to call parent class methods
- Polymorphism
  - Method overriding and duck typing
  - Operator overloading with dunder methods (`__str__`, `__eq__`, `__add__`, etc.)
- Composition and Advanced Concepts
  - Composition vs. inheritance
  - Abstract base classes
  - An introduction to multiple inheritance
- Final Project
  - Putting it all together: a final project that models a small system (e.g. a library, a game, or an inventory) using classes, inheritance, and polymorphism.

By the end of this course, students will understand the core principles of object-oriented programming and will be able to design and implement class-based Python programs using encapsulation, inheritance, and polymorphism.
