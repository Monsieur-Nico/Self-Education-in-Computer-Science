# Software Development Tools

## What to Expect

This is a short, practical section on the tools that surround actual programming: version control (Git), IDEs and how to use one well beyond just typing code into it, debugging and profiling tools, and the basics of build automation and continuous integration.

Topics covered:

- Version control systems (Git)
- Integrated development environments (IDEs)
- Debugging and profiling tools
- Build automation and continuous integration (e.g., GitHub Actions, Jenkins)

Realistically, you've probably already been using Git and an editor informally since Programming Fundamentals — this section is about deepening that into real fluency (branching, resolving conflicts, debugging tools beyond `print()`) rather than a first introduction.

## What to Prepare

**Prerequisites:** [Programming Fundamentals](/#programming-fundamentals-4-6-weeks) — you should already be comfortable running your own code; this section is about the tooling around that, not programming itself.

A few things worth knowing going in:

- **Git is the one tool here worth genuinely mastering**, not just using at a surface level — branching, merging, resolving conflicts, and understanding what a commit actually is will keep paying off for the rest of your career, technical or not.
- **The Eclipse tutorial covers one specific IDE** — if you're already using something else (VS Code is the most common choice today), it's completely fine to substitute that tool's own documentation instead. The point is fluency with *an* IDE, not Eclipse specifically.
- **Build automation and CI will make more sense once you've felt the pain they solve.** If it feels abstract right now, that's normal — it clicks once you've manually done a repetitive task enough times to want to automate it.
