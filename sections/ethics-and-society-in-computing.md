# Ethics and Society in Computing

## What to Expect

By this point you have real technical ability, which is exactly why this section matters: it's about the consequences of that ability. You'll cover the ethical issues computing raises, its social and political effects, privacy, intellectual property, and computing's impact globally — the questions that come up once code you write actually affects real people.

Topics covered:

- Ethical issues in computing
- Social and political implications of computing
- Privacy and security issues
- Intellectual property and copyright
- Global impact of computing

There's no single "correct" framework here the way there is in, say, algorithms — expect this section to be more about developing judgment than memorizing answers.

## What to Prepare

**Prerequisites:** none formally — this section is intentionally placed near the end so you're reasoning about ethics with real technical experience behind you, but it doesn't require any specific earlier section.

A few things worth knowing going in:

- **This section rewards relating the material to decisions you've actually seen or made**, not just abstract cases — think about tradeoffs in projects you've already built (what data did you collect, who could that code affect) as you go through it.
- **The Code (the book) is history and narrative, not a course** — read it for context on how Silicon Valley and the tech industry got the way it is, not for a structured curriculum.
- **It's fine to disagree with a source.** This material is genuinely debated by people who work in the field — the point is engaging with the arguments, not accepting a single "official" position.
