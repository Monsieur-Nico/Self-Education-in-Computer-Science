# Web Development

## What to Expect

This section is about building for the browser end to end: how a page is structured and styled (HTML/CSS), how it becomes interactive (JavaScript), how a server handles requests and talks to a database, and how to keep the whole thing reasonably secure. Unlike most other sections, this one is taught almost entirely through project-based curricula rather than lecture courses — you'll be building real, working things from very early on.

Topics covered:

- Front-end development (HTML, CSS, JavaScript)
- Back-end development (web frameworks, server-side programming)
- Database integration (SQL, ORM)
- Security and authentication

This is one of the more open-ended sections — "web development" covers a lot of ground, and both resources below are full curricula you could reasonably spend months in, not something you'll finish in an afternoon.

## What to Prepare

**Prerequisites:** [Programming Fundamentals](/#programming-fundamentals-4-6-weeks), [Database Systems](/#database-systems-8-12-weeks) — the database integration topics in this section assume you already know basic SQL.

A few things worth knowing going in:

- **This section moves fast between technologies.** In a single project you might touch HTML, CSS, JavaScript, a backend framework, and a database — that breadth is normal for web development, not a sign you're being asked to learn too much at once.
- **Neither resource below has an official total-hours estimate** (see the table) — both are large, self-paced curricula. Don't be discouraged if this section takes noticeably longer than its 8-12 week label suggests; that label is a rough floor, not a ceiling.
- **Deploying something live, even something small, is worth doing early.** Both curricula walk you through it — seeing your own project actually reachable on the internet is one of the more motivating milestones in this whole program.
