# Data Structures and Algorithms

## What to Expect

This is one of the longest and most foundational sections in the curriculum — it's where you learn to reason about *how* your code performs, not just whether it produces the right answer. You'll move from the basic building blocks (arrays, linked lists, stacks, queues) through more advanced structures (trees, graphs, hash tables), then into the algorithmic techniques used to work with them efficiently: searching, sorting, recursion, dynamic programming, greedy algorithms, and divide-and-conquer.

Topics covered:

- Basic data structures (arrays, linked lists, stacks, queues)
- Advanced data structures (trees, graphs, hash tables)
- Algorithm analysis and design
- Searching and sorting algorithms
- Recursion
- Dynamic programming
- Greedy algorithms
- Divide and conquer algorithms

This section is also the one most directly tied to technical interviews — if that's part of why you're here, expect to revisit it more than once.

## What to Prepare

**Prerequisites:** [Programming Fundamentals](/#programming-fundamentals-4-6-weeks) — you should be comfortable writing your own functions, using loops and conditionals, and debugging code you didn't just copy from a tutorial before starting here.

A few things worth knowing going in:

- **Budget real time for recursion.** It's usually the first genuine conceptual wall in this section. If it doesn't click immediately, that's normal — work through it on paper before trying to code it.
- **Expect to work things out by hand, not just in an editor.** Tracing through a data structure or algorithm on paper or a whiteboard before implementing it is a normal, useful part of learning this material, not a shortcut you're skipping.
- **This is the longest section in the curriculum (12-16 weeks).** Pace yourself — it's fine to interleave it with lighter sections rather than doing it in one continuous block.
- The resources below aren't meant to all be completed — check the **Role** column to see which one fits how you want to learn.
