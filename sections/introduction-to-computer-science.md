# Introduction to Computer Science

## What to Expect

This is the entry point of the curriculum — a broad survey of what computer science actually covers, before you specialize into any one part of it. You'll get your first exposure to programming, a preview of algorithms and data structures (the full treatment comes later, in its own dedicated section), and an overview of how computers are organized under the hood.

Topics covered:

- Overview of computer science
- Introduction to programming
- Overview of algorithms and data structures
- Basic computer organization and architecture

You're not expected to come out of this section a proficient programmer — that's what Programming Fundamentals (next) is for. This one is about breadth and getting oriented, not depth.

## What to Prepare

**Prerequisites:** none — this is the starting point.

A few things worth knowing going in:

- **Nothing needs to be installed or set up beforehand.** CS50 in particular eases you into a code editor and toolchain as part of the course itself.
- **Expect exposure to more than one language.** CS50 deliberately moves through C, Python, SQL, and web basics (HTML/CSS/JavaScript) rather than staying in one — the point is to see how the same ideas show up differently across languages, not to master any single one yet.
- **Feeling like you're drinking from a firehose is normal here.** An overview course is supposed to move fast and touch a lot; it gets slower and deeper from Programming Fundamentals onward.
