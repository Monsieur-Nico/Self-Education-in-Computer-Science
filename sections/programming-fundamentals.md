# Programming Fundamentals

## What to Expect

This is where you go from reading about code to actually writing real programs. The previous section gave you a taste of programming; this one builds the muscle: variables and data, control flow, functions, the core data structures you'll use in almost every program you ever write, and your first real exposure to object-oriented programming.

Each topic below has its own outline page:

- [Introduction to Python programming language](/programming-fundamentals/introduction_to_python.md)
- [Control flow statements](/programming-fundamentals/control_flow_statements.md)
- [Data types and structures](/programming-fundamentals/data_types_and_structures.md)
- [Functions and modules](/programming-fundamentals/functions_and_modules.md)
- [Input and output operations](/programming-fundamentals/input_and_output_operations.md)
- [Debugging and error handling](/programming-fundamentals/debugging_and_error_handling.md)
- [Object-oriented programming concepts](/programming-fundamentals/object_oriented_programming.md)

They're written to be worked through roughly in the order listed — each builds on ideas from the one before it.

## What to Prepare

**Prerequisites:** [Introduction to Computer Science](/#introduction-to-computer-science-8-12-weeks) — you should already have Python installed and have written at least a few short programs.

A few things worth knowing going in:

- **You'll write far more code here than in the last section.** This is the shift from watching/reading about programming to actually producing it — expect that transition to feel slower at first.
- **Debugging is a skill you're building, not a sign you're doing something wrong.** Everyone's code breaks constantly at this stage. Learning to read an error message and track down what it's actually telling you is as much a part of this section as any single topic.
- **Set up a proper code editor if you haven't already** (VS Code is a common free choice) — you'll be living in it for the rest of the curriculum.
